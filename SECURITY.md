# Security

Do not file public issues containing credentials, setup URLs, sessions, widget pairing codes or tokens, personal messages, database files, or private server configuration.

For a vulnerability, use this repository's private vulnerability reporting if available. Otherwise contact the maintainer through their GitHub profile before disclosing sensitive details publicly. There is no promise of a response time or supported release window for this personal project.

Rotate compromised credentials and revoke affected sessions/widget connections. Removing a secret from the latest commit does not remove it from Git history; revoke it first. Only the signed-in owner can edit the collection, and reader/widget responses must remain limited to the server-selected daily note.
